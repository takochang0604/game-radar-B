| 玩家動機 | 強度 | 核心依據 |

| **競技精通（Mastery / Competition）** | 🟣🟣🟣 | Ranked 排位天梯、與全球同級玩家對戰，韓國評論「以後出的回合制對戰要怎麼超越這款」 |
| **IP 情懷（Fandom / Nostalgia）** | 🟣🟣🟣 | 系列老粉「以前只能在 Switch，現在手機隨時對戰，神遊戲」，菲律賓「手機上玩寶可夢，未來來了」 |
| **社交對戰（Social）** | 🟣🟣 | Private Battle 與好友家人對戰，多則 5★ 許願「增加朋友雙打模式」 |
| **收集養成（Collection）** | 🟣 | Roster Ranch／HOME 連動組隊，但本作收集深度刻意收斂，非主軸 |

**主要受眾：Pokémon 系列老玩家 ＋ 競技對戰愛好者**（推估以 16–34 歲男性為主）
- 熟悉屬性相剋、配招、努力值的系列玩家，追求公平的天梯競技
- 原本在 Switch 對戰、渴望手機隨時開打的核心客群

**次要受眾：輕度回合制策略玩家**
- 被 IP 與「免費」吸引入坑、想嘗鮮的泛用戶
- 通勤／課餘想來幾場短局對戰的上班族與學生

玩家組成：競技核心型 ~55%、IP 情懷嘗鮮型 ~45%。

### 核心玩法（Core Game）

- **回合制指令對戰**：沿用系列正統機制（屬性相剋、招式 PP、特性、道具、先制度），單打與雙打皆備
- **三種模式**：Ranked（排位天梯）、Casual（休閒）、Private（私人房，可與好友家人對戰）
- **賽季制競技**：依勝負調整排名，配對同級對手，主打「公平的硬核對戰」
- **Pokémon HOME 連動**：可從 HOME 帶入既有寶可夢出戰（佔用 Champions box 空間、不永久保存）

> 媒體共識：戰鬥系統紮實、上手門檻低，但線上對戰以外幾乎沒有內容（Metacritic 66、OpenCritic 45% 推薦）。

### 養成系統（Meta Game）

| 系統 | 有無 | 說明 |

| **寶可夢取得** | ✅ | Roster Ranch、HOME 轉入、商店三管道，免費玩家皆可取得 |
| **Box 容量** | ⚠️ | 初期僅約 30–35 隻，需訂閱 Membership 才能大幅擴充——跨市場負評重災區 |
| **Battle Team 管理** | ✅ | 組隊、配招、隊伍切換，會員可建更多隊伍 |
| **數值養成** | ✅ | 沿用系列努力值／個體值／等級體系 |
| **賽季重置** | ✅ | 隨賽季重置排名，維持天梯活力 |
| **單機 PvE 內容** | ❌ | 上線僅 186 種寶可夢、對戰外幾無內容，新鮮期短 |

### 變現設計

| 設計 | 評估 |
|:---|:---|
| **Membership 訂閱（月／年）** | ⚠️ 擴 Box、加 Battle Teams、Training Tickets、會員任務、加速 Victory Points——便利性訂閱，但被指「初期 Box 太小變相逼課」 |

| **非 Pay-to-Win** | ✅ 寶可夢與招式免費全可得，付費不提供戰力優勢——競技公信力的加分項 |

### 策略觀察

1. **IP 矩陣化覆蓋**：用卡牌／MOBA／AR／睡眠／對戰等截然不同玩法切分客群，Champions 補齊長期缺席的「核心競技對戰」一塊。
2. **生態綁定提黏著**：HOME 連動把主機玩家的寶可夢資產延伸到手機，拉高轉換與留存，也讓 HOME 訂閱本身更有價值。
3. **變現克制換口碑**：相較 TCG Pocket 的抽卡榨取，Champions 押注非 P2W 的長線競技社群——立意贏得好評，但也直接犧牲了短期付費深度。

## ⚠️ 關鍵風險

- 🚩 **變現天花板低**：免費榜霸榜卻換不到營收——上線一週各國營收榜全面回落（日 #11→#19、泰 #27→#46、台 #42→#55、菲 #29→#49、美直接掉出 Top 100），純競技＋非 P2W 缺乏深度付費點。
- 🚩 **內容單薄、留存堪憂**：Metacritic 66、發行僅 186 種寶可夢，線上對戰以外幾無內容，新鮮期一過下載動能恐難維持。
- 🚩 **連線穩定性拖累口碑**：多市場 1 星集中反映斷線、黑屏、戰鬥中卡頓，1 星佔比高達 19.6%。
- 🟡 **Box 容量逼課爭議**：初期僅 30–35 隻、訂閱才擴充，正反評論都點名，傷品牌好感與付費觀感。
- 🟡 **對戰平衡與配對信任**：玩家普遍質疑「遇付費玩家就輸」「命中／急所機率異常」，雖官方標榜非 P2W，競技公信力仍受考驗。
- 🟡 **單裝置登入限制**：跨裝置需反覆登入，與「隨時隨地對戰」的賣點自相矛盾。
