## 🎯 目標玩家定位

| 玩家動機 | 強度 | 核心依據 |
|:---|:---|:---|
| **休閒放鬆** | 🟣🟣🟣 | 「能讓我放空、減壓」「打發時間」,無廣告體驗獲正評肯定 |
| **闖關精通** | 🟣🟣🟣 | 數千關卡 ＋ Champion League 競技,「享受關卡挑戰」「停不下來」 |
| **團隊社交** | 🟣🟣 | Team 系統互送體力、團隊賽,「有個很棒的隊伍」「有歸屬感」 |
| **收集進度** | 🟣 | 解鎖 Episode、收集星星換獎勵,非主要驅動 |

**主要受眾：泛大眾休閒消除玩家**（推估 25–55 歲、女性偏多）
- 通勤、課餘、睡前短時段遊玩,追求輕鬆無壓力
- 對畫面難度不敏感,重視「消除爽感」與每日登入習慣

**次要受眾：長期忠誠老玩家 ＋ 買量嘗鮮者**
- 玩 5–10 年的死忠用戶,團隊綁定深
- 被買量素材吸引入坑的新用戶（但素材與實際落差大,留存存疑）

玩家組成：休閒打發時間型 ~60%、競技挑戰型 ~40%。

### 品類定位

| 層級 | 分類 |
|:---|:---|
| **大品類** | 消除解謎（Puzzle） |
| **子品類** | 方塊消除（Blast / Collapse） |
| **細分品類** | 關卡式消除 ＋ 團隊社交（Tap-to-Blast Saga） |

### 核心玩法（Core Game）

- **Tap-to-Blast 消除**：點擊兩個以上同色方塊群即消除（collapse 機制），比 Royal Match 的 swap-to-match 換位更快、更直覺
- **關卡闖關 ＋ 障礙**：數千關卡,各種關卡目標與障礙物,難度逐步爬升
- **Booster ／ Combo**：消除產生火箭、炸彈、彩球等特殊方塊,組合製造大範圍連鎖
- **Champion League**：賽季制競技排名,近期主推但因強制參加＋難度過高成為爭議核心

### 養成系統（Meta Game）

| 系統 | 有無 | 說明 |
|:---|:---|:---|
| **關卡進度／Episode** | ✅ | 闖關解鎖新章節,主要進度軸 |
| **Team 團隊系統** | ✅ | 互送體力、團隊賽,社交黏著的關鍵 |
| **Star 收集獎勵** | ✅ | 完成關卡收集星星換獎勵 |
| **Magic Disco 道具** | ✅ | 抄 Royal Match 的 Super Light Ball,Lv.291 解鎖,強化＋損失趨避 |
| **城堡建造／mini-game meta** | ❌ | 缺——競品 Royal Match 有,Toon Blast 純關卡推進,meta 深度落後 |

### 變現設計

| 設計 | 評估 |
|:---|:---|
| **出招續命 coin** | ⚠️ 「步數用盡」彈窗買 coin 續命是主力變現,被指刻意設難度牆逼課 |
| **Gold Pass（黃金通行證）** | ✅ 賽季通行證,符合品類慣例（惟有玩家反映購買未生效、無退款） |
| **Champion League** | 🔴 強制參加 ＋ 難度過高,大量負評,變現與體驗失衡 |
| **無廣告體驗** | ✅ 付費後幾乎無廣告,獲正評肯定 |
| **難度逼課設計** | 🔴 玩家普遍質疑特定關卡「不課金不可能過」「rigged」 |

## ⚠️ 關鍵風險

- 🚩 **變現過度引爆負評**：近期取樣 1 星佔 34%、負面率 48%,集中在 Champion League 強制逼課、難度牆、獎勵縮水——傷害品牌與口碑。
- 🚩 **暴衝僅靠單一市場買量、不可持續**：僅日本 1 國上榜（遠低於同類 2.3 國基準）,UA 驅動的衝榜一旦停投即回落,系統觀測存活僅 2 天。
- 🚩 **Meta 內容落後競品**：相較 Royal Match 缺城堡建造與 mini-game meta,中長期留存與 LTV 天花板受限。
- 🟡 **核心老玩家流失**：8–10 年死忠用戶抱怨「毀了這款遊戲」「退休族再也不花一毛」,存量價值正在流失。
- 🟡 **買量素材與實際不符**：「跟廣告演的完全不一樣」普遍,誤導性素材雖能拉量,新用戶轉換後留存恐差。

## 💡 重點

- ✅ **可參考**：8 年老遊戲靠單一市場集中買量 ＋ 賽季活動,4 天從 #100 衝進 Top10,是「老 IP 翻紅買量打法」的教科書級案例。

- 📌 **結論**：**這是 Zynga forever franchise 的買量回光操作——短期榜單亮眼,但變現過度、單一市場、meta 落後,屬「老兵的曇花一現」而非結構性復甦。**
